PLANETAS 3D · EXPLORADORES (Jovens Gênios)
==========================================

Instalação (uma vez só):

  1. Descompacte este .zip na raiz do projeto Next.js. Ele cria components/planetas/.
     O projeto usa src/? Mova para src/components/planetas.
  2. npm i three
     npm i -D @types/three
  3. import { Planeta } from '@/components/planetas'
     <Planeta id="planeta-03" tamanho={240} alt="Planeta Emoções" />

Os modelos 3D e os pôsteres não vêm no .zip: o componente busca tudo na web, pelo id.

Planetas: planeta-01 Mitologia · planeta-02 Empreendedorismo · planeta-03 Emoções · planeta-04 Artes
          planeta-05 Computação · planeta-06 Fantasia · planeta-07 Música · planeta-08 Terra

Planeta novo: quando o Design publica, é só usar o id novo (ex.: <Planeta id="planeta-09" />).
Não é preciso baixar nada de novo.
