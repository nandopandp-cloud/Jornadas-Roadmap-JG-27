PLANETAS 3D · EXPLORADORES (Jovens Gênios)
==========================================

Instalação (uma vez só):

  1. Descompacte este .zip na raiz do projeto Next.js. Ele cria components/planetas/.
     O projeto usa src/? Mova para src/components/planetas.
  2. npm i three
     npm i -D @types/three
  3. import { Planeta } from '@/components/planetas'
     <Planeta id="planeta-emocoes" tamanho={240} alt="Planeta Emoções" />

Os modelos 3D e os pôsteres não vêm no .zip: o componente busca tudo na web, pelo id.

Planetas (id = planeta-<nome>, sem acentos):
  planeta-mitologia · planeta-empreendedorismo · planeta-emocoes · planeta-artes · planeta-computacao
  planeta-fantasia · planeta-musica · planeta-terra · planeta-alfabetizacao · planeta-transito
  planeta-esportes

Planeta novo: quando o Design publica, é só usar o id novo (ex.: <Planeta id="planeta-<nome>" />).
Não é preciso baixar nada de novo.
